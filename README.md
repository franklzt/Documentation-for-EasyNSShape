# Documentation-for-EasyNSShape
Documentation for EasyNSShape is a Niagara-based plugin that turns parametric math formulas into GPU particle shapes. It ships 128 ready-to-use 2D/3D shape emitters and systems (89 2D, 27 3D, 12 multi-parameter 3D), each backed by an HLSL dynamic input, plus an editor shape browser for previewing, snapshotting and recording every shape.
